# 🎬 CineMate: Movie Review System

**CineMate** is a simple movie review system built as a side project to learn and practice SQL concepts. It simulates a basic platform where users can browse movies, leave reviews, and view aggregated ratings. The primary goal of this project was to gain hands-on experience with database design, SQL queries, and data relationships.

## 🚀 Project Goals

- 🎯 Practice SQL (DDL, DML, joins, subqueries, aggregation, etc.)
- 🛠️ Understand database schema design and normalization
- 📊 Build a realistic system that mimics user interaction with structured data

## 🧰 Tech Stack

- **Frontend**: Basic HTML/CSS (optional / placeholder UI)
- **Backend**: None (focus was on SQL logic and schema)
- **Database**: MySQL / SQLite (depending on setup)

## 🗃️ Features

- 🗂️ Movie catalog with genres and release years.
- 👤 Users table to simulate multiple reviewers.
- ✍️ Reviews table storing ratings and comments.
- ⭐ Average rating per movie using aggregation.

🧠 What I Learned
Database design using multiple related tables

Writing clean, optimized SQL queries

Using aggregate functions and joins effectively

Normalization and indexing basics

📌 Note
This is a learning project and may not include advanced error handling, UI polish, or production-grade practices. The focus is on clean schema design and effective SQL usage.
